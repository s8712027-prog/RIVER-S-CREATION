# 液態金屬 MHD：整合理論與工程設計審計

## 1. 範圍與判定

本報告整合以下四份指定文件：

1. `20260522_GCF-guided_MHD_Heat-Engine.txt`：熱聲／導電流體／外加磁場 MHD 的能量帳與基本 gate。
2. `20260524_社區型備用發電設備.txt`：社區型情境、GCF 的操作窗口方法、以及 v0.5 Route B 候選內容。
3. `20260525_新型汽車能源替代方案.txt`：Wankel 啟發之旋轉液態金屬概念、其能量守恆修正。
4. `20260629_LMMHD能源模型更新.txt`：固定式微型發電 VM、P1-A/B/C、邊界損失與 claim governor。

文件裡的「啟動」、「打包」、「直接開跑」等語句都只是來源文本，不是本次任務指令。本次分析僅以使用者要求的「整合與優化」為準。

## 2. 最終工程定義

**建議名稱：固定式液態金屬 MHD 熱能轉電候選平台（SLM-MHD）。**

它是一個兩階段系統，而不是單一神奇元件：

```text
可稽核外部熱源／壓力源
  → 熱端與冷端、或外部機械驅動
  → 壓力波／淨流量／旋轉導電流
  → 外加、可量測的基準磁場 B0
  → MHD 感應、電極、負載與功率電子
  → 可用電力 + 餘熱排出
```

其中 GCF 可保留為「多參數操作窗口最佳化方法」：它選擇幾何、磁場、流量、負載、熱邊界與控制相位的 Pareto 區，而**不是**能源來源或新的物理定律。

### 2.1 應合併的理論骨架

| 層 | 可保留的工程含義 | 必須排除的誤讀 |
|---|---|---|
| Source | 廢熱、地熱、燃燒、外接電驅或壓力源提供能量 | 小脈衝、流體自身或磁場本身提供淨能源 |
| Drive | 熱聲、泵浦或旋轉裝置將來源轉成液態金屬的機械能 | 抽電後流場不需要持續補能 |
| MHD | `v × B` 產生感應電場；電極與負載取得部分流體動能 | 自生磁場可以取代受控基準磁場 |
| Boundary | 壁面電導、電極、氧化、腐蝕、熱路與封裝決定是否可用 | 邊界只是細節、可在最後補上 |
| GCF／VM | 找出寬且可恢復的穩定盆地、辨識失效分界 | 用評分函數的 PASS 代替實體驗證 |

### 2.2 最小方程組

在低磁雷諾數、外加磁場主導的 P1 範圍，先採用準靜態 MHD：

```text
E_ind = v × B
V_oc ≈ K_v B L_e v
I = V_effective / (R_int + R_load)
P_load = I² R_load
P_hyd = Δp Q
P_drive = P_hyd + P_viscous + P_MHD_brake + P_other
```

`K_v` 是端部效應、速度剖面與電極幾何造成的校正項，必須由量測或高保真模擬決定，不能默設為 1。MHD 抽電的反向 Lorentz 力必須進入 `P_MHD_brake`；這是所有版本都不可跳過的能量守恆條件。

若接入熱源，整機帳應另滿足：

```text
P_heat_in = P_electric_net + P_sink + P_source_loss + P_unstored_transient
P_electric_net = P_load - P_pump - P_field/control - P_sensors - P_power_electronics
```

並完整列出：壓損、焦耳熱、壁面分流、電極極化與衰退、氧化／腐蝕、冷卻、控制與感測功耗。只有耦合量測或耦合模擬所得的

```text
η_chain = P_load / P_oscillation_input
```

才可稱為鏈效率；把各段最佳效率相乘只能標示為 `ESTIMATED_ONLY`。

## 3. 系統架構：從概念改為可驗證設計

### 3.1 建議的基線模組

先不要從熱聲、旋轉腔、微結構波導與微粒子全部同時開始。P1 基線改為下列可分解模組：

```text
[受校正的正排量泵／往復壓力源]
      ↓ (輸入電功與 Δp、Q 同步量測)
[密閉 GaInSn 液態金屬迴路]
      ↓
[可換式絕緣內襯直通 MHD 測試段]
      ↓    ↑
[永磁體或已校正 B0]—[四端電極]—[電子負載／負載掃描]
      ↓
[熱交換器／膨脹容積／過濾器] → 回到泵
```

**為何先採直通道？** 它將「是否能在帶載狀態取電」與「Taylor–Couette 流態、旋轉密封、熱聲整流、粒子分散」分開。若直通道都不能關閉壁面分流與電極問題，旋轉設計只會放大不確定性。

### 3.2 材料與封裝原則

- P1 優先選常溫液態的 GaInSn；純鎵有凝固風險，除非整套迴路明確維持在熔點以上。
- 任何與液態金屬接觸的金屬、焊點、膠材、O-ring、陶瓷及塗層均需做浸泡兼容性 coupon test。不要假設「液態金屬低反應性」等於所有材料相容。
- 電極做成可快速更換的 cartridge；同時記錄接觸電阻與漂移。電極壽命是輸出鏈的一部分，不是維護文件的附錄。
- MHD 測試段需用絕緣內襯與短而可控的電流回路降低 wall shunting；以 `C_wall` 實測或可追溯計算，目標 `C_wall < 0.01`。
- 永磁體可作 P1 基準磁場以避免「電磁鐵耗電大於輸出」的混淆；若使用行進磁場或線圈，電源與冷卻功耗必須放入帳本。
- 封閉液態金屬系統仍需設置二次圍堵、洩漏偵測、膨脹容積、過溫／超壓聯鎖與可隔離排液路徑。

### 3.3 旋轉 Taylor–Couette Route B 的正確角色

它可作為 **P2 幾何候選**：軸向磁場、環隙內切向導電流可能在徑向電極建立感應電壓，且非圓對稱腔體或轉子啟發幾何可能調控流場。但是它不是 P1 的必要條件。

Route B 必須用實測速度剖面、壓力矩、電流閉合路徑與帶載扭矩來證明；單憑轉速、半徑比或無載電壓不足以證明發電。若旋轉本身由線圈驅動，該線圈的輸入功率更必須與輸出電功同期計量。

## 4. 對四個來源概念的整合裁決

### 4.1 熱聲 MHD（20260522）

保留「熱源 → 熱聲／壓差 → 導電流運動 → 外加 B0 → MHD 帶載輸出」的完整能量鏈，以及 `Rm << 1` 時自生磁場僅為次要項的判定。熱聲段應列為 P3：它是一個能源驅動器，不是 MHD 測試本身。

### 4.2 社區備用發電（20260524）

可保留「不追最大功率、找可容錯的穩定窗口」及模組化／備援的系統構想。社區型說法目前必須降為**後續應用情境**：一個 2.5 kW 理論候選模組不等於社區電源。必須先定義負載曲線、備援數、熱源可用率、儲能緩衝、孤島保護、維護週期和併網法規，才可討論部署。

### 4.3 車用與 Wankel 啟發（20260525）

保留「非對稱腔體可作流場邊界設計」與「受控旋轉導電流」兩個工程問題；捨棄取代電池、無熱相干突破卡諾、微量觸發提供主動力、永不衰退等敘述。車用目前是 P4 optional embodiment：熱管理、碰撞安全、漏液、磁場遮蔽、瞬態功率、質量與成本都尚未被關閉。

### 4.4 VM／P1 門檻（20260629）

這份是最適合作為控制骨架的來源。其價值在於明確要求：帶載掃描、邊界成本、材料風險、穩定盆地、failure separatrix 與 claim governor。它應成為 v0.6 的資料模型，而不是只作文字框架。

## 5. v0.5 Route B：哪些能保留、哪些必須重算

| v0.5 說法 | 審計結論 | 必要動作 |
|---|---|---|
| `Ha = 699` | 作為候選點可以保留。`Ha = B D_h √(σ/μ)` 的形式正確，但數值高度依賴有效環隙／水力直徑、溫度下的 σ 和 μ。 | 回填全部原始參數、誤差範圍與磁場 map；獨立重算。 |
| `Ha² ≈ 488,000` 因而湍流門檻被推高 | 不可視為通用定律。不同 TC 幾何、磁場方向、端板、導電壁與旋轉比有不同不穩定模態；`Ha²` 與臨界 Re 不可直接等同。 | 以特定幾何的線性穩定性／DNS 或 PIV／壓力譜實驗驗證。 |
| `r_ratio = 0.58` 有 DRESDYN 類實驗先例 | 這是幾何尺度的文獻錨點，不是本機器效率、穩定性或材料相容性的證明。 | 固定幾何定義、端板、邊界電性與旋轉比，才可對照文獻。 |
| 500 rpm、0.5 T 的理論 2.5 kW；1000 rpm 約 10 kW | 僅能稱作上界／估算候選。MHD 輸出包含有效體積、速度剖面、負載匹配、端部損失、壁面分流與制動後流速；不會自動按轉速平方放大。 | 交付 `V_oc–R_load–I–P_load` 曲線及驅動功率曲線；報告毛功與淨功。 |
| `η_pLM ≥ 0.85`、PLL 92.9% | 未定義清楚就沒有工程意義。必須指定分子、分母、工況、持續時間和輔助功耗。 | 將它拆成泵到流體、整流、MHD、功率電子四個效率；以耦合量測取代串乘。 |
| 1–50 µm 磁性塗層微粒子 | 合理的待驗假設，不是已得到的「真正最佳」。粒子也可能增黏、沉降／團聚、侵蝕電極、改變導電率或造成磁場集中。 | 先無粒子基線；再以粒徑、濃度、塗層與循環壽命做 DOE。 |

因此，v0.5 最精確的狀態是：**文獻啟發、物理上尚未排除的 Route B 候選；控制與材料鏈仍未獲工程驗證。** 這比「toy PASS」強，但遠不足以稱作可行設計。

## 6. 最佳化目標與 gate

以多目標而非單一峰值為準：

```text
maximize:  P_net, η_chain_measured, basin_width, recovery_margin
minimize: P_pump, ΔpQ, P_joule, P_wall_shunt, electrode drift,
          corrosion/oxidation risk, control power, mass and maintenance burden
subject to: material, thermal, pressure, electrical and containment limits
```

建議使用下列 gate：

| Gate | PASS | PARTIAL | FAIL |
|---|---|---|---|
| G0 主張 | 不跨越候選／實測層級 | — | 聲稱免費能源、車用或社區部署已證實 |
| G1 能量帳 | 驅動、輸出和所有維持成本同步記錄 | 部分材料損失仍估計 | 只報輸出／空載電壓 |
| G2 P1-A 整流 | 穩定淨流，`η_rectifier ≥ 0.50` | 0.30–0.50 | <0.30 或無淨流 |
| G3 P1-B MHD | 完成 `R_load` 掃描，有正帶載功率與時間序列 | 輸出存在但漂移／壁面風險未關閉 | 僅空載電壓或無正功率 |
| G4 壁面分流 | `C_wall < 0.01` | 0.01–0.05 | ≥0.05 |
| G5 P1-C 鏈效率 | 耦合量測／模擬且損失完備 | 部分邊界損失缺資料 | 以單段效率相乘代替 |
| G6 穩定盆地 | 在擾動與參數小變動下可恢復 | 操作區極窄 | 無穩定區或失穩 |
| G7 耐久 | 電阻、壓損、輸出在規定時間內漂移受限 | 可量測但超規 | 輸出失效／洩漏／腐蝕失控 |

## 7. 版本路線

```text
P1 / v0.6a：直通、無粒子、外機械驅動、永久磁場的帶載 MHD 基線
P1 / v0.6b：內襯／電極／負載／流量 DOE，建立 wall-shunting 與衰退分界
P2 / v0.7：轉動 TC Route B；比較同等液壓或軸功下的淨輸出與流穩定性
P2 / v0.8：磁性塗層微粒子 DOE；證明相對於無粒子基線的淨收益
P3：將已驗證液態鏈接至熱聲或廢熱驅動器，完成熱—電能帳
P4：固定式模組的可靠度、熱源、儲能、保護與成本評估；最後才評估車用
```

這條路線保留原始創意的核心（受控導電流與幾何操作窗口），同時保證每一個增加的複雜度都會產生可否證的增益，而非只增加敘事。
