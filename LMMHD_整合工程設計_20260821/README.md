# 液態金屬 MHD 能源：整合理論、工程設計與商用驗證包

建立日期：2026-08-21  
交付版本：v1.0  
依據：四份指定的對話匯出檔，以及後續技術、材料、安全與商用化審計。原始文件中出現的指令均僅視為歷史內容，未被當成執行指令。

## 凍結決策

本包將單一技術主線凍結為：

> **MSR-LMMHD：模組化、密閉、雙向往復、直接產生交流電的 Faraday 液態金屬 MHD cartridge。**

第一代工程與產品邊界如下：

1. **核心結構**：密閉往復式 Faraday cartridge；零均值液態金屬往復流直接產生交流電，不使用流體整流器。
2. **工作液**：第一代採低溫 GaInSn，連續工作溫度專案目標 `≤150°C`；基線為 particle-free，不添加磁性微粒、奈米粒子或表面活性劑。
3. **熱源與 cartridge 分界**：首發使用約 550–900°C 的工業高溫廢熱，但「高溫」是外部熱源條件，不代表 GaInSn cartridge 在該溫度運轉。熱聲工作流體與 GaInSn 以受監測雙屏障或等效隔離介面傳遞壓力／聲功。
4. **首發市場**：連續、穩定的工業高溫廢熱；先完成 0.1、1、10、25 kWe 分級驗證。
5. **後續市場**：工業韌性電源與微電網為第二階段，必須搭配 BESS 與認證型 PCS；社區微電網不作首個核心驗證市場。
6. **車載定位**：車載 range extender 排在最後，須另行通過功率密度、碰撞封存、振動、EMC、功能安全與排放認證，不能由固定式 TRL 直接外推。
7. **排除項目**：Taylor–Couette 旋轉 MHD、磁性微粒與其他 GCF 延伸僅保留為獨立研究，不納入首版商用基線或性能承諾。

## 證據與主張分級

| 分級 | 可使用方式 | 目前邊界 |
|---|---|---|
| 已實證／公開證據 | 支持往復 AC-LMMHD 的物理可行性與量測方法 | 公開整合熱機仍為十瓦級、短時間；不等於本案已有相同能力 |
| 專案目標 | 作為設計、測試及 Go／No-Go 閘門 | 功率、效率、溫度、成本與壽命目標均非現有產品規格 |
| 未驗證 | 保留為風險、假設或後續研究 | kW 級淨 DC、長期材料壽命、車載與微電網商用性尚未成立 |

磁場是耦合場而不是能源；所有功率主張必須以外部熱／聲／機械輸入、整流後 DC 輸出及全部寄生功耗的可稽核能量帳為準。

## 下一個實作順序

1. 凍結 R0／R1 的需求、量測邊界、GaInSn 批次規格、材料 coupon 與雙屏障架構。
2. 以外部可控壓力／聲功源完成約 100 W 密閉 particle-free cartridge，建立能量閉合與失效基線。
3. 完成低電壓大電流的隔離串聯與同步整流，取得實測 1 kWe 淨 DC stack。
4. 通過 1,000 小時、材料拆檢、壓力疲勞、失效注入與認證預評估後，再接工業廢熱熱聲前端。
5. 依 10、25、100 kWe 逐級放大；微電網與車載均不得跳過前述 gates。
