# v0.6：材料、感測器與帶載 MHD 驗證規格

## A. v0.6 的唯一目標

建立一份可重算的證據鏈：在已量測的機械輸入功率下，密閉液態金屬迴路能否在受控外加磁場中提供穩定的**帶載** MHD 輸出；同時量出其邊界損失與材料漂移。

這不是整機熱效率、也不是車載或社區部署測試。

## B. 儀器與量測閉環

| 節點 | 最低量測 | 用途 |
|---|---|---|
| 驅動器 | 供電電壓／電流或扭矩／轉速；同步功率分析 | 得到真實 `P_drive`，避免只算流量 |
| 流體 | `Q`、入口／出口 `Δp`、溫度、液位 | `P_hyd = ΔpQ`、壓損、黏度校正 |
| 磁場 | 測試段 3D `B(x,y,z)` map、溫度 | 取得有效 B 與磁體漂移 |
| 電極 | 四線式接觸阻抗、`V_oc`、`I_load`、`R_load` | 區分接觸損失與液體內阻 |
| 負載 | 可程式電子負載／電阻陣列，完整負載掃描 | 確認最大功率點與穩定區 |
| 材料 | 質量、影像／內視、coupon、溶出／表面分析 | 追蹤氧化、腐蝕、潤濕、侵蝕 |
| 安全 | 壓力、溫度、漏液、二次圍堵狀態 | 連鎖停機與故障歸因 |

所有功率與壓力資料應以共同時鐘記錄；時間平均前保留原始訊號，才能辨識相位延遲、瞬態充放電與控制功耗。

## C. v0.6a 基線 DOE（先不加磁性微粒）

固定流體批次與幾何，掃描：

```text
B:       0 → B_design，至少 4 個點
Q / v:   低、中、設計、高 4 點
R_load:  覆蓋 0.25 R_int、0.5 R_int、R_int、2 R_int、4 R_int
T:       最低安全溫度、標稱溫度、最高安全溫度
time:    每一點穩態後連續記錄；另做長時漂移測試
```

必做對照：`B = 0`；無流；極性反轉；電極位置互換。這些控制組能排除熱電效應、量測偏置與電源耦合假訊號。

每一點至少輸出：

```text
timestamp, B_map_id, Q, Δp, T_in, T_out, P_drive,
V_oc, R_int_4wire, R_load, V_load, I_load, P_load,
P_hyd, P_joule, P_wall_shunt, P_control, P_net,
C_wall, electrode_age, material_batch, alarm_state
```

## D. 關鍵計算與一致性檢查

```text
P_hyd        = Δp Q
P_load       = V_load I_load
P_net_stage  = P_load - P_control - P_sensors - P_field_maint
η_chain      = P_load / P_oscillation_input   # 僅在分母同步實測時使用
η_drive      = P_oscillation_input / P_heat_available  # 熱源版本才使用
Ha            = B D_h √(σ/μ)
Rm            = μ0 σ v L
N             = σ B² L / (ρ v)
```

必須同時檢查：

1. `V_oc` 對 `Bv` 的近似線性區是否存在；斜率給出實際 `K_v L_e`。
2. `P_load(R_load)` 是否在接近 `R_load = R_int` 出現合理最大值；偏離時要以電極極化、非均勻電流或控制誤差解釋。
3. 開啟負載後的 `Q`、`Δp` 或軸扭矩是否增加／速度是否下降；這是 Lorentz 制動能量帳的直接證據。
4. `B=0` 或 `Q=0` 時，輸出是否回到可量測的背景範圍。
5. 所有淨效率一律以誤差棒表示，並說明功率計、流量計、壓力計和磁場 map 的不確定度。

## E. 材料與微粒子 v0.6b

微粒子不是基線必要元件。只有 v0.6a 通過 G1/G3/G4 後才加入。用最小 DOE 回答「是否有淨收益」：

| 因子 | 建議層級 |
|---|---|
| 粒徑 | 1–5、10–20、30–50 µm |
| 濃度 | 0、低、中；由黏度和沉降限制決定 |
| 塗層 | 至少兩種與 GaInSn 兼容候選 |
| 磁場 | 低／標稱／高 |
| 流速 | 低／標稱／高 |

判定不是看瞬時 `P_load` 變高，而是比較同等 `P_drive`、同等運行時長時的：

```text
ΔP_net, ΔP_pressure_loss, ΔR_int, drift rate,
sedimentation/agglomeration, electrode wear, C_wall
```

只有 `ΔP_net > 0` 且耐久／壓損沒有惡化到抵銷收益，才能保留微粒子路線。

## F. P2 Route B 專屬要求

若將 v0.5 的 Taylor–Couette 方案帶入，新增以下必要資料：

```text
inner/outer radius, axial length, gap, endcap design,
rotation ratio, wall electrical conductivity, B orientation/map,
torque-speed curve, radial electrode geometry, current-return path,
velocity profile or validated CFD, vibration spectrum
```

以 `Ha = 699` 或 `Re = 262852` 作為測試候選點可以，但不可將它們單獨當作 P1 成立的證明。P2 的通過條件是：與直通道基線比較後，在相同 `P_drive` 與安全邊界下，具有可重複的正 `ΔP_net` 或更寬穩定盆地。

## G. 交付標準

一次可審計 run 至少包含：原始資料檔、儀器校正與精度、測試幾何圖／版本、材料批次、資料處理腳本版本、完整能量帳、所有 gate 結果、失效／異常紀錄與禁止主張檢查。

最終標籤僅能是下列之一：

```text
SIGNAL_PASS              # Bv 相關帶載訊號存在
CHAIN_PASS               # 耦合液態鏈有正帶載輸出
CLOSURE_CANDIDATE        # 淨帳與邊界在穩定盆地內有希望
PARTIAL_BOUNDARY_INCOMPLETE
FAIL
```

未實測前，v0.5 的正確標籤仍為 `LITERATURE_GROUNDED_CANDIDATE`。
