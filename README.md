# RIVER'S CREATION

A public laboratory for unfinished ideas, experimental code, and projects with room to grow.

This repository is intentionally a work in progress. Some experiments may be incomplete, disproven, or paused. That is part of the design: useful ideas often become clearer through visible iteration.

## What you will find here

- Research notes and development records in [shared/outputs](shared/outputs)
- Python prototypes and test files
- Experimental results in Markdown and JSON
- New project spaces in [ideas](ideas)
- Paused work in [archive](archive)

## Start here

If you are visiting for the first time, begin with:

1. Browse the files in [shared/outputs](shared/outputs).
2. Open a Markdown report to understand the motivation and current state.
3. Look for related Python files when you want to inspect or reproduce an experiment.
4. Check the latest commits to see what is changing.

## How to participate

You are welcome to read, discuss, test, improve, or challenge the ideas here.

- Open an Issue for a question, observation, bug, or possible direction.
- Fork the repository and submit a Pull Request with a proposed change.
- Explain what you changed, why it matters, and how you tested it.
- Please keep experiments focused and preserve useful context in the project README or commit message.

See [CONTRIBUTING.md](CONTRIBUTING.md) for a short contribution guide.

## Status

This is an evolving collection rather than a finished product. Please treat results as experimental unless a file explicitly says otherwise.
