# GCF Tubular Patent Figures

This folder contains the latest v4.2 candidate figure package for the GCF tubular chip design.

Contents:

- PNG figures for visual review
- SVG figures for editable vector use
- INDEX.txt describing the figure set

The package is shared for research, design discussion, and technical review. The repository owner has confirmed that there is currently no plan to pursue a patent application for this material. The files are therefore published as an open technical reference package, not as a filed patent or legal patent document.

The v4.2 candidate archive is retained as the canonical copy. Exact duplicates and older v4.1 archives were not uploaded.
