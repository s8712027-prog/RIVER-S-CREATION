# Contributing

Thank you for taking a look at RIVER'S CREATION.

## Ways to help

- Read an experiment and leave a constructive Issue.
- Reproduce a result and report what happened.
- Suggest a clearer explanation or a useful next test.
- Fork the repository and open a Pull Request.

## Pull Requests

Please include:

- A short summary of the change
- The files or experiment affected
- Any commands or tests you ran
- Open questions, limitations, or unexpected results

Small, focused contributions are easiest to review. Please do not include passwords, API keys, private data, generated caches, or unrelated large files.
