# GCF UMA

GCF-UMA is a research-stage generic adapter and integration middleware package. It defines contracts, branch routing, transaction boundaries, recovery behavior, and host-binding semantics for multiple GCF-related branches.

## Version progression

- v0.1: reusable schema, capability, authority, provenance, unit, and host binding.
- v0.1a: branch multiplexing, contract negotiation, role isolation, and ambiguity blocking.
- v0.1b: sessions, replay protection, transactional lifecycle, outage recovery, idempotent execution, and compensation.
- v0.1c: append-only local journal, restart reconstruction, host-receipt reconciliation, compensation boundaries, and explicit multi-host semantics.

## Evidence boundary

The packages contain synthetic or locked mock tests and research-stage implementation material. They are not complete algorithms, production middleware, distributed consensus, real atomic commit, cryptographic identity, safety certification, or validated energy/fusion/6G deployment software.

The four versions are published for technical review and research discussion. The exact duplicate file named with "(1)" was excluded.
